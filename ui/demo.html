How it plays

  1. Holes. The chart, punched. Each chord tone is a chain of holes on its own row; the bass gets one slot on every beat, the way the band is told to strike it.
  2. Pencil. The tune. The band hears it too, but it is pencilled, not punched, because it is the part you can take. The live app can mute the melody so the band leaves it to you.
  3. Light. The recording. A hole lights as it crosses the brass bar, as bright as the take is loud in its register: bass slots by the low end, chord holes by the middle.
  4. Margin. Printed as each change crosses the bar: +7 ms is late, −78 ms early, missed means never found.
  5. Heard. The chord a detector heard on each beat, ringed in red where it is not the chart’s chord.

Run it

The band is a real-time music model on your Mac’s GPU, so it needs Apple Silicon. A browser can only play back what it recorded. Install Python 3.12, uv and Node first. The engine release asset is not yet published, so live playback is not ready from a fresh clone. For the recorded demo: 

git clone https://github.com/intesarjawad/ghostband.git
cd ghostband
make setup
npm --prefix ui run dev

Open the local address printed by Vite followed by /demo.html. View the repository.
